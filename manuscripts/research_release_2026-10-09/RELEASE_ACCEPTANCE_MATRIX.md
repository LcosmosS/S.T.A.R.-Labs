# Release acceptance / negative outcome matrix

This file defines a submission-preparation checklist, not an editorial acceptance guarantee.

| Evidence component | Paper I M1 | Paper II arithmetic | Paper III physical |
| --- | --- | --- | --- |
| Governing Charter PDF and frozen preregistration | Required | Required | Required |
| Claim ID, class/population/scope, signed independent review | Required | Required | Required |
| Exact derivation incl. sign/conventions, complete proof or qualified candidate | Essential | Mathematical-statistical specification | Essential mechanism |
| Source provenance, SHA256, license, environment, fixed code and versions | Exact symbolic verifier + optional numerical checker | Ecdata and controlled runner | Every astronomical/simulation source |
| All negative and positive raw output + immutable manifests | Counterexample or failed lemma diagnostics | All 999 null values and independent rerun | All blinded prediction residuals and controls |
| Independent mathematical verification / replication | Independent proof review **not present** | Independent controlled reproduction **not present** | Independent physical validation **not present** |
| Explicit null/alternative, multiple testing, selection/sensitivity policy | Class-limited factorization/sufficiency | Locked rank permutation (others separately registered) | Source/mask/cosmic variance and physics baselines |
| Current status | Candidate + corroborating numerical spot checks | Frozen protocol **not executed** | Hypothesis **not eligible** |
| Legitimate negative paper | Proof of insufficiency if independently accepted; otherwise reproducibility/methodology report | Valid rank-permutation non-rejection or rejection with limitations | Scoped retirement of P0 search frame if independently audited |

## Versioned submission recipe

- [ ] Actual selected arXiv category + journal scope and formatting instructions verified (Oxford Academic is a publishing platform, not one uniform journal format).
- [ ] Versioned LaTeX article(s) compile cleanly, table and caption sources trace to immutable computed artifacts; no placeholders in submitted results or abstract.
- [ ] DOI/citation records checked against original papers, no ghost citations or misunderstood physical sign conventions.
- [ ] Repository release/tag identifies canonical reviewed commit, exact source hashes, independent review and CI results.
- [ ] Data privacy, licenses, distribution rights, author contribution/COI/funding and any generative-AI assistance declared as journal requires.
- [ ] Results and null values frozen before prose conclusions; any after-the-fact work clearly marked exploratory or successor preregistration.
- [ ] Unknown/failed/inconclusive prerequisites plainly stated; no “100% validated/guaranteed acceptance” claim.

**Do not submit** a results abstract for paper II/III until eligible results exist. Keep immutable correction records after future retractions or errors.
