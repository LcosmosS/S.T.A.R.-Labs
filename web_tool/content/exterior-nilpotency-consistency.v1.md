# Exterior derivative nilpotency — mathematical consistency note v1

**Classification:** D (mathematical identity). **Physical support:** none.

Let ℳ be a globally defined smooth scalar field on a smooth manifold. The exterior derivative of the scalar is the globally exact one-form θ=dℳ. The exterior derivative satisfies d²=0; hence

```text
θ = dℳ
ω = dθ = d(dℳ) = 0
[ω] = 0 in de Rham H²
```

The identity cannot simultaneously establish a nontrivial de Rham class for ω. A globally defined two-form with [ω]≠0 must be closed but not globally exact, and therefore cannot globally be written ω=dθ for a globally defined θ.
