## Generation and inspection

Date: 2026-10-16. Mode: built-in `image_gen` image editing, using the original
raster assets as edit targets. The prior galaxy web, telescope, mathematical
overlays, and implied arithmetic/cosmology correspondence were removed.
STARMAP branding and a restrained navy/gold palette were retained.

The README banner was generated in two editing passes. The social card was
edited using its original image as target and the revised README banner as a
style/content reference. The generated social source was 1731 x 909 PNG,
SHA-256 `75e8ca9be4872dbaaa24682c9bdd2cab103acf8ab4ba554ca0e5834e53df467f`;
it was resized without cropping to the existing 1200 x 630 delivery size and
encoded as JPEG at quality 92. This final format normalization did not add or
remove content. The README banner was copied without re-encoding.

The final repository PNG and JPEG were decoded and inspected at delivery
dimensions. Checks covered text accuracy, numerical values, caveat visibility,
contrast, clipping, and absence of cosmological correspondence imagery.
The source experiment, permutations, and neighbor graph were not executed or
regenerated during visual production.
