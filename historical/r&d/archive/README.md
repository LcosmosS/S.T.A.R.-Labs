# Historical R&D Archive

This directory preserves material migrated from the former repository-level `archive/` directory.

The contents are retained as historical research and development artifacts. They are **not** part of the controlled notebook suite and are not automatically treated as evidence for any registered claim.

## Provenance

- Original location: `archive/`
- Migrated to: `historical/r&d/archive/`
- Migration purpose: align the repository with the Research Charter while preserving prior exploratory work.
- Files are retained without scientific reinterpretation or silent cleanup.

Some entries are generated/intermediate artifacts (for example Python bytecode, editor checkpoint/backup files, and trash metadata). They remain here solely for provenance; they should not be used as controlled inputs.

## Controlled research

For controlled experiments, use the experiment, dataset, parameter, null-model, and claim registries together with the canonical notebooks documented in the repository README and Research Charter.
