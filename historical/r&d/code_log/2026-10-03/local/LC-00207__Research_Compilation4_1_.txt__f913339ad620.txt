The user needs to define z_bins to group the data by redshift ranges. Previous suggestions included z_bins = [0, 0.05, 0.1, 0.15, 0.2, 0.25, 0.3, 0.35, 0.4], which creates bins with steps of 0.05 up to 0.4. Alternatively, the user can base bins on the actual range of z_filtered:
                                                                     * Compute min_z = vecmin(z_filtered); and max_z = vecmax(z_filtered);.
                                                                     * Define bins with equal intervals, for example:
num_bins = 8;  // Adjust as needed
step = (max_z - min_z) / num_bins;
                                                                     * z_bins = vector(num_bins + 1, i, min_z + (i-1)*step);
