1. Purpose
The S.T.A.R. Experiment Registry converts claims in the Claim/Evidence Registry into executable, falsifiable experiments.
The Registry answers:
Exactly what experiment will test each claim, using what data, what mathematical construction, what controls, what null model, and what constitutes success or failure?
The Registry is deliberately stricter than the historical ACSC experimental descriptions.
Historical experiments remain preserved, but a new experiment must distinguish:
[
\text{historical demonstration}
]
from
[
\text{preregistered validation experiment}.
]
________________


2. Governing Experimental Principle
Every experiment must follow:
[
\boxed{
\text{Claim}
\rightarrow
\text{Prediction}
\rightarrow
\text{Dataset}
\rightarrow
\text{Locked Construction}
\rightarrow
\text{Null}
\rightarrow
\text{Test}
\rightarrow
\text{Independent Evaluation}
}
]
The experiment may not be modified after inspection of the primary test results unless the modification is recorded as a new exploratory experiment.

5. Global Experimental Standards
5.1 No post-hoc threshold selection
A threshold discovered after seeing the result cannot be presented as the primary criterion.
________________


5.2 Historical thresholds are controls, not acceptance standards
The historical:
[
W_2<0.01
]
criterion is retained because it is part of the ACSC record.
It is not automatically accepted as the scientific decision threshold.
The primary modern evaluation shall use a null distribution and effect-size comparison.
________________


5.3 Alternative mappings are mandatory
Whenever (\Phi) is tested, at least one non-(\Phi) mapping must be tested under comparable conditions.
The principal alternative family is:
* MCJ;
* PTD;
* FT.
These are explicitly identified in the alternative-mapping document as BSD-independent alternatives.
________________


5.4 Rank cannot be evaluated in isolation
For rank-based experiments, the minimum arithmetic comparison set is:
[
r,\quad
\log\operatorname{Reg},
\quad
\log N,
\quad
\log|\Delta|,
\quad
T.
]
Where data availability permits, the composite feature vector is:
[
X_E=
(r_E,
\log\operatorname{Reg}_E,
\log N_E,
\log|\Delta_E|,
T_E).
]
________________


5.5 Significance is not predictive utility
Every predictive experiment records both:
[
\text{statistical significance}
]
and
[
\text{out-of-sample predictive utility}.
]
A statistically significant but practically negligible effect is recorded as such.
________________

7. EXP-A01 — Rank–Cosmic-Web Morphology
Experiment ID
[
\boxed{\text{EXP-A01}}
]
Claim
CROSS-001
Arithmetic rank may be related to cosmic-web morphology.
________________


Scientific Question
Does elliptic-curve rank contain statistically reproducible information about whether an astronomical environment is classified as cluster, filament, or void?
________________


Primary Hypothesis
[
H_1:
P(r\mid C,F,V)
]
differs systematically from the appropriate null distribution.
________________


Null Hypothesis
[
H_0:
r
\perp
\text{cosmic-web environment}
]
after controlling for relevant observational and sampling covariates.
________________


Astronomical Dataset
Primary candidate:
SDSS galaxy catalog / volume-limited sample.
The ACSC source specifically proposes SDSS galaxy coordinates and a volume-limited sample.
Dataset version
TBD — exact SDSS release/catalog must be frozen before preregistration.
Population
A predefined volume-limited galaxy sample.
Required fields
At minimum:
* RA;
* Dec;
* redshift;
* galaxy identifier.
Additional fields should be retained for covariate control.
________________


Cosmic-Web Classification
The classification pipeline must be frozen before rank analysis.
Cluster
Use an independently defined cluster/group catalog or cluster-density classification.
Filament
Use primarily:
* geometric skeleton;
* graph;
* filament-finder methodology.
Persistent homology may provide supporting topological characterization but shall not itself define “filament = (\beta_1).”
Void
Use an independently defined void catalog or void-finding algorithm.
________________


Arithmetic Dataset
Candidate source:
* LMFDB;
* Cremona database;
* independently generated elliptic curves where required.
The ACSC monograph specifically identifies LMFDB and Cremona as arithmetic sources.
________________


Arithmetic Variables
Primary:
[
r_E.
]
Secondary:
[
\log\operatorname{Reg}(E),
\quad
\log N_E,
\quad
\log|\Delta_E|,
\quad
T_E.
]
________________


Mapping
For the rank-specific experiment:
[
z_E=200r_E
]
may be retained as the historical mapping, but it is not itself treated as physical.
________________


Critical Matching Problem
The experiment must define how astronomical objects are assigned arithmetic objects.
This cannot be chosen after observing the results.
Matching protocol
TBD — must be preregistered.
Possible choices include:
1. rank distribution comparison without one-to-one object matching;
2. fixed stochastic assignment;
3. deterministic binning;
4. projection-space density comparison.
A direct galaxy-to-curve identity should not be assumed.
________________


Null Model
Primary:
[
H_0^{\rm perm}
]
randomly permute rank labels across astronomical environments while preserving the observed rank distribution.
Secondary nulls:
* spatial permutation;
* redshift-stratified permutation;
* density-matched permutation.
________________


Locked Parameters
Before execution:
* sample definition;
* redshift limits;
* environment classifier;
* rank computation/version;
* arithmetic sample;
* matching rule;
* spatial smoothing scale;
* binning;
* random seed;
* statistical test.
________________


Train/Test Design
This experiment is primarily inferential.
Use:
* discovery/training partition for any model selection;
* held-out test partition for final association.
No environment classifier may be tuned using rank.
________________


Primary Endpoint
Effect of rank on environment classification after covariate adjustment.
Candidate primary statistic:
\text{performance}_{\rm rank}
\text{performance}_{\rm null}.
]
Exact metric:
TBD — preregister before execution.
________________


Success Condition
A successful result requires:
1. statistically significant deviation from the primary null;
2. non-negligible effect size;
3. persistence across reasonable observational controls;
4. replication on held-out data;
5. no equivalent or stronger explanation from obvious covariates.
________________


Failure Condition
Failure occurs if:
* rank does not outperform null;
* the effect disappears after controls;
* effect is confined to training data;
* effect is attributable to survey geometry or selection;
* alternative randomization reproduces the effect.
________________


Reproducibility
Must include:
* raw-data identifiers;
* preprocessing script;
* exact rank source/version;
* random seed;
* classifier version;
* environment-definition file;
* immutable result table.
________________

9. EXP-A03 — Arithmetic/Cosmic Persistent-Homology Correspondence
Experiment ID
[
\boxed{\text{EXP-A03}}
]
Claim
ACSC-002
Arithmetic projection produces a topological signature that corresponds to cosmic structure.
________________


Historical Construction
\left(
\log_{10}|\Delta|,
\log_{10}N,
200r
\right).
]
This is explicitly the projection used in the ACSC monograph.
________________


Astronomical Dataset
Primary:
SDSS volume-limited 3D galaxy sample.
Secondary:
* cosmological simulation;
* independent survey.
The ACSC source proposes SDSS, 2dF, Euclid, and Millennium Simulation as possible observational/simulation sources.
________________


Arithmetic Dataset
Primary:
LMFDB/Cremona elliptic curves with required invariants.
________________


Primary Topological Objects
[
D_k^{\rm arith},
\qquad
D_k^{\rm cosmic},
\qquad
k=0,1,2.
]
________________


Primary Comparison
Wasserstein distance:
[
W_p(D_k^{\rm arith},D_k^{\rm cosmic}).
]
________________


Historical Criterion
The source specifies:
[
W_2<0.01
]
as a historical threshold.
This is retained as:
[
\boxed{\text{Historical Criterion H-W2}}
]
but is not the primary modern acceptance threshold.
________________


Primary Null
Generate randomized arithmetic projections preserving:
* number of points;
* coordinate marginal distributions;
* relevant scaling;
* sample size.
The cosmic dataset should similarly be subjected to spatial nulls where appropriate.
________________


Alternative Nulls
N1 — Coordinate permutation
Shuffle arithmetic invariant associations.
N2 — Rank permutation
Preserve (\log N) and (\log|\Delta|), randomize rank.
N3 — Random projection
Generate an equivalent-dimensional random mapping.
N4 — Alternative arithmetic mapping
Use MCJ/PTD/FT.
________________


Critical Normalization Rule
Wasserstein distances are sensitive to scale.
Therefore:
Arithmetic and astronomical point clouds must be normalized using a procedure frozen before comparison.
No normalization may be selected because it minimizes (W_2).
________________


Primary Endpoint
The primary endpoint is not simply:
[
W_2<0.01.
]
It is:
\frac{
W_{\rm null}-W_{\rm observed}
}{
\sigma_{\rm null}
}
]
or an equivalent preregistered null-relative statistic.
________________


Success
Observed correspondence must outperform the null distribution with:
* statistically significant separation;
* meaningful effect size;
* robustness to normalization;
* persistence across reasonable sample sizes;
* independent replication.
________________


Failure
ACSC correspondence is not supported if the observed topology is statistically indistinguishable from null mappings or if the correspondence disappears under reasonable normalization choices.
________________


Important Filament Rule
[
\boxed{
\beta_1\neq\text{“number of filaments” by definition}.
}
]
Filament correspondence must additionally be evaluated through geometric/graph/skeleton structure.
________________


10. EXP-A04 — Alternative Mapping Control Experiment
Experiment ID
[
\boxed{\text{EXP-A04}}
]
Claim
MAP-006
MCJ, PTD, and FT provide meaningful BSD-independent controls for (\Phi).
________________


Purpose
Determine whether apparent success is specific to the proposed arithmetic structure or is produced generically by low-dimensional projections.
________________


Mapping Families
Primary
[
\Phi:
(\log|\Delta|,
\log N,
\alpha r).
]
MCJ
(j)-invariant-based mapping.
PTD
Purely arithmetic mapping.
FT
Frobenius-trace-based mapping.
The alternative-mapping document explicitly proposes these families as alternatives to the primary (\Phi) construction.
________________


Locked Principle
All mappings must receive:
* identical sample size;
* identical observational target;
* identical topology algorithm;
* identical distance metric;
* identical normalization procedure;
* identical null-generation procedure.
________________


Null
Random mapping preserving coordinate distributions.
________________


Primary Endpoint
Relative null-adjusted topological correspondence:
\text{performance}(m)
E[\text{performance(null)}].
]
________________


Success
The result supports mapping specificity only if:
[
S_\Phi
]
is reproducibly distinguishable from both null mappings and alternative arithmetic mappings.
________________


Failure
If all mappings perform similarly, the evidence supports a generic projection/topology effect rather than specificity of (\Phi).
This is not necessarily a failure of topology itself; it is a failure of the claim that the particular arithmetic construction is responsible.
________________

Experiment ID

Arithmetic-only

]

R^2_{\rm combined}
R^2_{\rm baseline}.

Other metrics:

Secondary:
* redshift-stratified permutation;
* mass-stratified permutation;
* spatial permutation.

Spatial/grouped split preferred.
A galaxy from the same structural group should not appear simultaneously in training and test when that could create leakage.

The existing S.T.A.R. methodology may use:

* Gradient Boosting;
* symbolic regression;

[
\boxed{
\text{ML discovery}\neq\text{physical proof}.
}

________________

Arithmetic features produce a reproducible improvement in held-out prediction after:
* astrophysical controls;
* null comparison;
* leakage testing;
* independent validation.
________________

________________

18. Experiment Result Classification
A completed experiment receives one of the following outcomes.
PASS — Statistical Correspondence
The predicted relationship is statistically distinguishable from the null.
This does not imply physical causation.
________________


PASS — Predictive Utility
The relationship improves independent out-of-sample prediction by a practically meaningful amount.
________________


FAIL — Null Consistent
The observed relationship is consistent with the null.
________________


FAIL — Alternative Explanation
The relationship disappears after controls or is equally explained by an alternative mapping.
________________


FAIL — Specific Prediction
The particular prediction is contradicted.
________________


INCONCLUSIVE
Data quality, computational limitations, or insufficient sample size prevent a valid conclusion.
________________

24. Controlling Experimental Principle
The S.T.A.R. Experiment Registry adopts the following permanent rule:
A result cannot become evidence for a stronger claim merely because the analysis that produced it was successful.
Each result supports only the proposition actually tested.
Therefore:
[
\boxed{
\text{Experiment}
\rightarrow
\text{Claim}
}
]
is always explicit.
And:
[
\boxed{
\text{Claim}
\not\Rightarrow
\text{Theory}
}
]
unless the intervening mathematical and empirical evidence has independently been established.
________________


25. Registry Closing Statement
The Priority A program now has a controlled experimental architecture capable of distinguishing three very different outcomes:
[
\boxed{\text{interesting numerical correspondence}}
]
[
\boxed{\text{reproducible statistical relationship}}
]
[
\boxed{\text{independent predictive evidence}}.
]
Only the latter stages justify progressively stronger scientific interpretation.
The immediate goal is therefore not to demonstrate ACSC.
The immediate goal is to determine, under fixed and independently testable conditions:
[
\boxed{
\textbf{whether any arithmetic signal survives appropriate null models and independent astronomical validation.}
}
]
That result—positive, negative, or inconclusive—is the scientific output of the Priority A program.
