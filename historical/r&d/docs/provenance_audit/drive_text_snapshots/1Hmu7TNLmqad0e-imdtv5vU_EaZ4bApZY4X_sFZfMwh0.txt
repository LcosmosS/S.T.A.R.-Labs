# ACSC-GLMPCT: Symbolic Projections from Arithmetic Geometry to Cosmological Structure


[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/LcosmosS/ACSC-GLMPCT/HEAD?urlpath=lab)


## Overview


This repository supports the formalization, analysis, and validation of the **Arithmetic–Cosmic Structure Conjecture (ACSC)** and the **Global-to-Local Mapping Paradox Correction Theory (GLMPCT)**. The project investigates the hypothesis that large-scale cosmological structure—filaments, voids, and clustering—emerges from the symbolic projection of elliptic curve invariants into 3D topological space.


**ACSC-GLMPCT** is an interdisciplinary research project that constructs explicit computational analogies between the world of arithmetic geometry (specifically invariants of elliptic curves) and the large-scale structure of the universe. By mapping mathematical invariants—such as discriminant, conductor, rank, and regulator—onto spatial and statistical coordinates in a cosmologically inspired 3D space, the project explores new ways to visualize, analyze, and interpret the deep connections between number theory and cosmology.




> **Key Idea**: Arithmetic geometry (e.g., elliptic curves over (\mathbb {Q}) encodes symbolic patterns which, when projected using computable mappings, replicate the persistent homology of observed cosmic structures.


This work is **inspired by** (but not dependent on) the Birch and Swinnerton-Dyer (BSD) conjecture and builds a full BSD-independent symbolic projection system.


## Key Features


- **Mathematical Rigor:**  
  - Computes advanced invariants for elliptic curves (analytic/algebraic rank, regulator, Heegner points, BSD checks) using SageMath and PARI/GP.


- **Cosmological Mapping:**  
  - Projects these invariants onto a notional "cosmic web," with area- and shape-preserving mapping strategies inspired by planetary science and cosmology.


- **Modern Computation:**  
  - Utilizes parallelization, dynamic resource management, checkpointing, and logging for robust, large-scale computation.
  - Symbolic regression and machine learning are used for coordinate discovery and computational efficiency.


- **Visualization:**  
  - Produces high-quality, interpretable 3D plots and statistical summaries of the mapped "cosmic" structure.


- **Reproducibility and Modularity:**  
  - Modular Python code (data generation, invariants, mapping, visualization) with up-to-date documentation and test cases.


- **BSD-independent Projection Functions**:
  - PTD Mapping (Period–Torsion–Discriminant)
  - MCJ Mapping (Modularity–Conductor–j-invariant)
  - FT Mapping (Frobenius Trace statistics)


- **Topological Data Analysis (TDA)**:
  - Persistent homology computed using `Ripser` and `GUDHI`
  - Wasserstein distance and Betti number comparison to SDSS/Millennium simulation data


- **Symbolic Regression**:
  - Discover emergent relationships (e.g., symbolic energy, curvature) using `PySR` or `gplearn`


- **Reproducibility Tools**:
  - Jupyter notebooks, precomputed arithmetic and cosmological datasets
  - Docker/conda environments for consistent computation
  - Null model generation for statistical significance testing

## BSD Disclaimer


> **Note**: This work is **inspired by** the conceptual structure of the Birch and Swinnerton-Dyer conjecture, particularly the rank–height–L-function relationship, but **no step in the projection, simulation, or topological analysis depends on BSD being true**.


All methods operate on explicitly computable, algebraic invariants.

## Quick Start


**Prerequisites:**  
- [SageMath](https://www.sagemath.org/) ≥ 10.6  
- Python 3.8+ with numpy, matplotlib, scikit-learn, joblib, sympy, psutil  
- Linux/macOS recommended (Windows: use WSL2 or a Linux VM)


**Installation:**  
```bash
git clone https://github.com/LcosmosS/ACSC-GLMPCT.git
cd ACSC-GLMPCT
pip install -r requirements.txt
```


**Run the Main Pipeline:**  
```bash
sage -python main.py
```
*See `USAGE.md` for detailed setup, options, and troubleshooting.*
