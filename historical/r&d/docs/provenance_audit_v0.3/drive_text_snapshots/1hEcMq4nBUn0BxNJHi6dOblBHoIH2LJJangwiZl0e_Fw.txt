S.T.A.R.
Claim → Evidence → Experiment Crosswalk
Purpose
This crosswalk connects the v0.2 Claim/Evidence Registry to the existing S.T.A.R. research and development archive.
It answers four questions for every active claim:
1. What existing R&D evidence can be used now?
2. What evidence requires reconstruction or validation before use?
3. What experiment formally tests the claim?
4. Is the next step reconstruction, controlled re-analysis, or an entirely new experiment?
The crosswalk deliberately distinguishes:
[
\boxed{\text{Existing Evidence}}
\neq
\boxed{\text{Validated Evidence}}
]
Existing R&D can therefore be scientifically useful while remaining exploratory, historical, or reconstruction-required.
________________


1. Evidence-State Legend
Code
	Evidence state
	Meaning
	U
	Usable R&D Evidence
	Existing artifact can enter the evidence chain as historical, theoretical, computational, or pilot evidence
	R
	Reconstruction Required
	Existing result is potentially valuable but methodology/data/code must be reconstructed before controlled use
	N
	New Experiment Required
	Existing R&D does not adequately test the claim
	C
	Control
	Existing material can provide a baseline/null/control
	D
	Derivation Audit
	Mathematical derivation exists but requires formal verification
	H
	Historical Only
	Preserved for provenance; not evidence for current claim
	X
	Negative/Diagnostic
	Existing result identifies instability, limitation, or contradictory behavior
	These states may coexist.
For example:
[
\boxed{U+R}
]
means useful historical evidence exists, but reconstruction is required before promotion to controlled evidence.

}

The central objective of v0.2 is consequently not to maximize the number of “supported” claims.
It is to make every claim answerable to a specific question:
What evidence supports this claim, where did that evidence come from, what experiment tests it, what null could defeat it, and what remains to be done before the evidence can be considered reproducible?
That is the controlling relationship for the S.T.A.R. research program.
